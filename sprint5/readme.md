# TITAN Projetos - Sprint 5

Projeto da sprint 5. Depois de muito sofrimento e raiva acumulada com o Prisma

## 📋 Pré-requisitos

- Node.js 20.19.6
- npm 

## 🚀 Configuração do Projeto

### Clonar este repositório 

## git clone https://github.com/Jean-Carlo89/TITAN-projetos.git

### Entrar na pasta TITAN-projetos

## cd TITAN-projetos


### Entrar na pasta sprint-5

## cd sprint5


### npm install


### npm run prisma:generate
Gere o cliente Prisma com base no schema

### npm run dev
Inicie o servidor de desenvolvimento

### o projeto vai rodar em  http://localhost:3000





## já deixei o arquivo .env e .dev.db comitados para facilitar e não precisar rodas as migrations.
